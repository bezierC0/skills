## 1. 内容証明郵便

**役割**：いつ・誰が・誰に・どんな内容を送ったかを郵便局が証明する。意思表示の到達（解除・取消し・催告）の証拠、時効の完成猶予（催告から6か月、民法150条）、相手への心理的効果。

**形式（紙で出す場合）**：縦書きは1行20字以内・1枚26行以内、横書きも同等の字数制限の形式がある。同文3通（相手・郵便局・自分控え）。配達証明を付けるのが通常。インターネットで出せる「e内容証明」もある。形式は郵便局の最新案内を確認するよう伝える。

**雛形（金銭請求）**：

```
　　　　　　　　　　請求書

　私は、貴殿に対し、令和【　】年【　】月【　】日、【貸付・売買代金等の原因】として金【　】円を【支払期限】の約定で【貸し付けました／債権を有しています】。
　しかし、期限を過ぎた現在も支払がありません。
　つきましては、本書到達後【14】日以内に、下記口座へ金【　】円をお支払いください。
　期限内にお支払いいただけない場合は、法的手続をとることを予定しておりますので、あらかじめ申し添えます。

　　　　　　　　　　　　記
　【振込先口座】

令和【　】年【　】月【　】日
　　（差出人）住所【　】氏名【　】
　　（受取人）住所【　】氏名【　】殿
```

**文面の注意**：
- 事実と請求内容を簡潔に。感情的な非難や、相手の家族・職場への通知をほのめかす表現は脅迫・強要・名誉毀損のリスク。「法的手続をとる」は適法な予告。
- 請求額・根拠を正確に。過大な請求は交渉上不利。
- 相手から内容証明が届いた場合：記載の期限は法的な期限ではないことが多いが、無視せず、事実関係を確認して回答方針を決める。認める・認めないを不用意に書かない。

## 2. 手続の選び方（請求する側）

| 手続 | 対象・特徴 |
|---|---|
| 支払督促 | 書類審査のみ。相手が異議を出すと通常訴訟に移行（相手の住所地の裁判所） |
| 少額訴訟 | 60万円以下の金銭請求。原則1回の期日で判決（民事訴訟法368条以下）。相手が通常訴訟への移行を求めれば移行 |
| 民事調停 | 話し合い。費用が安く非公開 |
| 簡易裁判所の通常訴訟 | 訴額140万円以下 |
| 地方裁判所 | 訴額140万円超。本人訴訟も可能だが弁護士推奨 |
| 労働審判 | 労働事件（`labor.md`） |
| ADR | 各種業界団体・弁護士会の紛争解決センター |

費用：訴額に応じた収入印紙と郵便切手（予納郵券）。裁判所ウェブサイトの手数料額早見表で確認。民事訴訟手続のIT化（オンライン提出等）が段階的に進んでいるので、提出方法は管轄裁判所の案内を確認する。

## 3. 訴状・支払督促が届いたとき（請求された側）

**最重要：放置しない。**
- 通常訴訟：答弁書を出さず第1回口頭弁論期日に欠席すると、相手の主張を認めたものとみなされ（擬制自白、民事訴訟法159条）、相手の請求どおりの判決が出る可能性が高い。
- 支払督促：受け取ってから2週間以内に督促異議を出さないと、仮執行宣言が付され、強制執行（給与・預金の差押え）が可能になる。
- 特別送達の封筒・期日呼出状に、期日と答弁書の提出期限が書いてある。最初に必ず確認させる。

**やること**：
1. 期日・答弁書提出期限をカレンダーに記録
2. 訴状の請求の趣旨（何を求められているか）と請求の原因（相手の主張する事実）を確認
3. 事実ごとに「認める／否認する／知らない（不知）」を整理
4. 証拠を集める
5. 弁護士・法テラスに相談するか判断（地裁の事件、高額、複雑なら強く推奨）
6. 答弁書を期限までに提出（第1回期日は、答弁書を出していれば欠席しても陳述したものとみなされる：民事訴訟法158条。ただし簡裁以外で続行期日は出頭が必要）

架空請求の注意：本物の裁判所からの書類は「特別送達」で届く。メールやSMS、ハガキで「訴訟最終通知」等と来るものは詐欺の可能性が高い。ただし、本物か疑わしいときは、書類記載の番号ではなく、自分で調べた裁判所の代表番号に問い合わせるよう伝える。

## 4. 答弁書の作り方

裁判所が訴状と一緒に送る答弁書の書式があればそれを使う。なければ以下の構成：

```
令和【　】年（【　】）第【　】号 【事件名】
原告　【　】
被告　【　】

　　　　　　　　　答　弁　書

令和【　】年【　】月【　】日
【　】裁判所　御中
　　　　　　　被告　【住所・氏名】　印
　　　　　　　（送達場所・電話・FAX）

第1　請求の趣旨に対する答弁
　1　原告の請求を棄却する。
　2　訴訟費用は原告の負担とする。
との判決を求める。

第2　請求の原因に対する認否
　1　請求の原因第1項は認める。
　2　同第2項のうち、【　】は認め、その余は否認する。
　3　同第3項は不知。

第3　被告の主張
　【否認の理由、抗弁（弁済済み、時効、相殺、契約解除など）を具体的に】

第4　証拠
　乙第1号証　【　】

附属書類
　1　答弁書副本　1通
　2　乙号証写し　各2通
```

**ポイント**：
- 認否は正確に。認めた事実は後で争えなくなる（裁判上の自白）。分からないことは「不知」。
- 争う理由がまだ整理できなければ「追って主張する」と書いて、まず期限内に出すことを優先する。
- 消滅時効を主張するなら「時効を援用する」と明記（援用しないと裁判所は時効を考慮しない、民法145条）。
- 分割払いで和解したい場合も、答弁書にその旨を書いて期日に出頭する（簡裁では和解に代わる決定もある）。

## 5. 準備書面・陳述書

- **準備書面**：期日の前に主張を書面で提出。構成は「第1 原告の主張に対する反論 → 第2 被告の主張の補充 → 第3 証拠」。相手の主張を一つずつ特定して反論する。期日の1週間前程度までに提出するよう指示されることが多い。
- **陳述書**：本人の体験した事実を時系列で書く。尋問の前提となる。
  - 自分の言葉で、具体的に（日時・場所・誰が・何を言ったか）
  - 推測や評価ではなく事実中心
  - 自分に不利な事実も隠さず、説明を加える（尋問で突かれると信用性を失う）
  - 虚偽を書かない（当事者尋問での虚偽陳述は過料、証人の偽証は偽証罪）
- **証拠の番号**：原告は甲第◯号証、被告は乙第◯号証。証拠説明書を添える。

## 6. 期日・法廷での主張（本人訴訟）

- **服装・態度**：特別な決まりはないが、落ち着いて裁判官に向かって話す。相手方を攻撃しない。
- **口頭弁論**：実際は「準備書面のとおり陳述します」で終わることが多い。書面で主張を尽くすことが最重要。
- **裁判官の質問への答え方**：結論から短く。分からないことは「確認して次回書面で回答します」と言ってよい。
- **当事者尋問の準備**：
  - 自分の陳述書を読み込み、時系列を頭に入れる
  - 相手方からの反対尋問で聞かれそうな不利な点を洗い出し、事実に基づく答えを準備する（答えを作り変えるのではなく、説明の仕方を整理する）
  - 質問の意味が分からなければ聞き返す。覚えていないことは「覚えていません」と答える
- **和解**：多くの民事訴訟は和解で終わる。裁判官から和解の打診があったら、譲れる範囲・最低ラインを事前に決めておく。和解調書は判決と同じ効力（強制執行可能）を持つ。
- このスキルの役割は、主張の整理・書面化・想定問答の準備まで。証言内容を事実と異なるものにする指導は行わない。

## 7. 判決後

- 控訴期間：判決書の送達を受けた日から2週間（民事訴訟法285条）。少額訴訟は控訴できず、異議申立て（2週間以内）。
- 判決に従わない相手 → 強制執行（預金・給与の差押え）。相手の財産が分からない場合は財産開示手続・第三者からの情報取得手続。

## 8. 刑事事件について

刑事事件（被疑者・被告人の立場）は、本人だけで対応すべきではない。
- 逮捕されたら当番弁護士を呼べる（初回無料）。資力がなければ国選弁護人。
- 黙秘権がある。供述調書は内容を確認し、違っていれば訂正を求め、納得できなければ署名しなくてよい。
- 被害者の立場：被害届・告訴、被害者参加制度、損害賠償命令制度、各都道府県の被害者支援センター。
このスキルでは制度の一般的説明にとどめ、弁護人への早期相談を必ず勧める。
