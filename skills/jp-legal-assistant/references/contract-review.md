## 1. レビューの進め方

1. **立場の確認**：ユーザーはどちら側か（委託者／受託者、売主／買主、事業者／消費者）。立場で「有利・不利」が逆転する。
2. **契約の性質決定**：タイトルではなく中身で判断する（「業務委託」でも実態が雇用なら労働法が適用されうる。請負か準委任かで責任が変わる）。
3. **全体を読む → 条項ごとにリスク判定**：各条項を 🔴高（署名前に修正必須）／🟡中（交渉推奨）／🟢低（許容範囲）で分類。
4. **欠けている条項を指摘**：書いていないことは民法等の任意規定で補われる。それがユーザーに不利なら追加を提案する。
5. **修正案を提示**：現行文言 → 修正案 → 理由 の形で。交渉の落とし所（代替案）も示す。

## 2. 共通チェック項目

| 条項 | 確認ポイント |
|---|---|
| 目的・業務範囲 | 範囲が曖昧だと追加作業・無償対応の争いになる。成果物・作業内容を具体的に |
| 対価・支払条件 | 金額、税込／税抜、支払期日、検収との連動、遅延時の扱い |
| 検収 | 検収期間、みなし検収（期間内に通知なければ合格）の有無 |
| 契約不適合責任 | 2020年民法改正で「瑕疵担保責任」から変更。買主・注文者は追完・代金減額・損害賠償・解除が可能（民法562〜564条）。不適合を知った時から1年以内に通知が必要（566条、種類・品質の場合）。特約で期間短縮・免責される場合が多いので確認 |
| 損害賠償 | 上限額（例：直近12か月の委託料）、間接損害・逸失利益の除外、故意・重過失の場合の上限除外の有無 |
| 知的財産権 | 成果物の権利帰属、移転時期（支払完了時か）、著作者人格権の不行使、既存の権利・汎用部品の留保。著作権法27条・28条の権利は「特掲」しないと譲渡人に留保と推定される（61条2項） |
| 秘密保持 | 定義、例外（公知情報など）、存続期間、返還・廃棄 |
| 再委託 | 可否、事前承諾、再委託先の責任 |
| 解除 | 解除事由、催告の要否、中途解約の可否と予告期間・違約金 |
| 期間・更新 | 自動更新の有無、更新拒絶の通知期限 |
| 反社会的勢力の排除 | 各都道府県の暴力団排除条例により一般的。欠けていれば追加を提案 |
| 競業避止 | 範囲・期間・地域が過大だと無効の可能性。対価の有無も判断要素 |
| 準拠法・管轄 | 専属的合意管轄が相手方の本店所在地だと、遠方での訴訟負担が生じる |
| 印紙税 | 紙の契約書は課税文書の場合がある（不動産売買は第1号、請負は第2号、継続的取引基本契約は第7号文書など）。電子契約は印紙不要。貼り忘れても契約は有効だが過怠税の対象 |

## 3. 契約類型別の注意点

- **請負 vs 準委任**：請負は仕事の完成義務（民法632条）、準委任は善管注意義務での事務処理（656条・644条）。システム開発・コンサルでは区別が争点になりやすい。準委任にも「成果完成型」がある（648条の2）。
- **NDA**：一方向か双方向か、残存条項、損害賠償の予定額。
- **利用規約・定型約款**：定型約款の要件と、相手方の利益を一方的に害する条項は合意しなかったものとみなされうる（民法548条の2第2項）。変更手続（548条の4）。
- **保証契約**：個人が根保証をする場合、極度額の定めがないと無効（465条の2）。事業用融資の個人保証は公証人による意思確認が原則必要（465条の6）。
- **金銭消費貸借**：利息制限法の上限（元本10万円未満 年20%、10万〜100万円未満 年18%、100万円以上 年15%）。超過部分は無効。

## 4. 立場による強行法規・特別法

契約に書いてあっても、次の法律に反する部分は無効・違法になりうる。必ず該当性を確認する。

- **消費者契約法**（相手が消費者の場合）：事業者の損害賠償責任を全部免除する条項は無効（8条）、平均的損害を超える解約金は超過部分無効（9条）、消費者の利益を一方的に害する条項は無効（10条）。不当勧誘による取消し（4条）。
- **特定商取引法**：訪問販売・電話勧誘販売等のクーリング・オフ（原則8日、連鎖販売等は20日）。通信販売にはクーリング・オフはなく返品特約による。
- **下請代金支払遅延等防止法（下請法）**：2026年1月施行の改正で法律名・用語が変わり（中小受託取引適正化法、いわゆる取適法）、適用範囲も拡大している。現行条文と公正取引委員会・中小企業庁の解説を必ず確認する。支払期日（受領から60日以内）、減額・返品・買いたたきの禁止などが中心。
- **フリーランス・事業者間取引適正化等法**（2024年11月施行）：個人で従業員を使用しない受託者への発注では、取引条件の明示、支払期日（60日以内）、ハラスメント対策などが求められる。
- **借地借家法**、**労働基準法**等：各リファレンス参照。

## 5. 出力形式（修正案）

```
■ 総合評価：署名前に修正が必要な箇所 X件 / 交渉推奨 Y件
■ 条項別レビュー
第◯条（損害賠償） 🔴
  現行：「乙は、本契約に関して甲に生じた一切の損害を賠償する。」
  問題：上限なし・間接損害を含む。受託者として過大なリスク。
  修正案：「乙は、本契約に関して甲に生じた損害につき、直接かつ通常の損害に限り、本契約に基づき甲が乙に支払った直近12か月分の委託料を上限として賠償する。ただし乙の故意又は重過失による場合はこの限りでない。」
  落とし所：上限を契約金額総額とする案。
■ 追加すべき条項
■ 相手方との交渉メモ（伝え方の例）
```
