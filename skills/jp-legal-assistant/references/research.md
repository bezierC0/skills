# 調べ方・改正分野・相談先

## 1. 一次情報の確認先

| 内容 | 情報源 |
|---|---|
| 現行条文 | e-Gov法令検索（laws.e-gov.go.jp）。法令API V2もある |
| 判例 | 裁判所ウェブサイトの裁判例検索（courts.go.jp）。最高裁判例は事件番号・年月日で特定 |
| 労働 | 厚生労働省のパンフレット・通達、各労働局 |
| 不動産 | 国土交通省（原状回復ガイドライン、人の死の告知ガイドライン）、各都道府県の宅建業担当 |
| 消費者問題 | 消費者庁、国民生活センター |
| 下請・フリーランス取引 | 公正取引委員会、中小企業庁 |
| 裁判手続・書式・手数料 | 裁判所ウェブサイト（各種申立書式、手数料額早見表） |
| 内容証明の形式 | 日本郵便 |

ツール環境での使い方：
- Web検索やURL取得が使えるなら、改正分野の条文・判例は回答前に確認する。
- 日本法令取得用のスキル（例：e-Gov法令APIを使う jp-law スキル）が入っていれば、条文の取得にはそちらを使う。
- ツールがない環境では、確認すべき条文名・番号と情報源を示し、「現行条文を確認してください」と書く。

## 2. 改正に特に注意する分野

知識が古い可能性が高いので、回答時は改正の有無を意識する：

- 民法（債権法）：2020年4月施行。瑕疵担保→契約不適合、消滅時効（知った時から5年／権利を行使できる時から10年、166条）、法定利率（3%からの変動制、404条）、定型約款、保証
- 民法（相隣関係・共有・相続登記）：2023〜2024年施行。相続登記の申請義務化（2024年4月）
- 民法（親子・家族法）：嫡出推定の見直し（2024年施行）、離婚後の共同親権の導入（2026年4月施行）
- 下請法 → 中小受託取引適正化法（2026年1月施行）
- フリーランス・事業者間取引適正化等法（2024年11月施行）
- 区分所有法（マンション関連の改正）
- 民事訴訟法（IT化、段階的施行）
- 労働法：労働時間規制の適用拡大（建設・運送・医師 2024年4月〜）、労働条件明示ルール（2024年4月〜）、育児介護休業法の改正（2025年〜段階施行）
- 刑法：拘禁刑の創設（2025年6月施行、懲役・禁錮を一本化）、性犯罪規定の改正（2023年）

## 3. 相談先

| 相談先 | 内容 |
|---|---|
| 法テラス（0570-078374） | 収入・資産が一定以下なら無料法律相談、弁護士費用の立替え |
| 各地の弁護士会の法律相談センター | 有料（30分5,500円程度が多い）、分野によって無料相談あり |
| 市区町村の無料法律相談 | 予約制が多い |
| 司法書士 | 登記、簡易裁判所の事件（140万円以下）は認定司法書士が代理可能 |
| 行政書士 | 官公署への書類作成（紛争性のある代理は不可） |
| 社会保険労務士 | 労務管理、労働局のあっせん代理（特定社労士） |
| 総合労働相談コーナー | 各労働局・労基署内。無料 |
| 消費生活センター（188） | 消費者トラブル全般 |
| 警察相談（#9110） | 緊急でない警察への相談。緊急時は110 |

電話番号・料金は変わることがあるため、正式な案内は各機関のサイトで確認するよう添える。
